# Séance du 24/02/2026

Sujet : Utilisation de l'IA pour faire le refactoring du [Trivia Kata Refactoring](https://github.com/jbrains/trivia). 


# Instructions 

1. Installer les dépendances : `npm install`
2. Exécuter le code : `npm run start`
3. Exécuter les tests : `npm test`

# Déroulement de la séance

La séance s'est déroulé autour des étapes suivantes :
* Demande de génération du fichier [REGLES_METIER.md](./REGLES_METIER.md) avec les règles métier
* Demande de génération du fichier [EVALUATION_QUALITE_CODE.md](./EVALUATION_QUALITE_CODE.md) avec une évaluation de la qualité du code
* Ajout de tests unitaires
* Suivi de la couverture de code par les tests
* Refactoring du code de prod
